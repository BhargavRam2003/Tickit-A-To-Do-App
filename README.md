# Tickit-A-To-Do-App

TickIt is a Python-based to-do list application designed to help users efficiently manage their daily tasks. It provides a simple yet powerful interface for tracking and organizing tasks.

🚀 **Features**


📝 Task Management – Add, update, mark as complete, and delete tasks effortlessly.

💾 Data Persistence – Stores tasks using file handling or SQLite.

🎨 User-Friendly UI – Built with Flask, HTML, CSS, and Bootstrap for a responsive interface.

⚡ Scalable & Optimized – Designed for future GUI enhancements and extended functionality.


🛠 **Tech Stack**

Backend: Python, Flask

Frontend: HTML, CSS, Bootstrap

Database: SQLite / File Handling


📦 **Installation & Usage**

1️⃣ Clone the Repository

git clone https://github.com/yourusername/TickIt.git
cd TickIt

2️⃣ Install Dependencies

pip install -r requirements.txt

3️⃣ Run the Application

python app.py
